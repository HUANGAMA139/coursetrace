# 测试与验证

## 不收费的基础检查

在已安装工具的项目根目录运行：

~~~powershell
.\scripts\maven.ps1 test
.\scripts\pnpm.ps1 --dir client build
~~~

当前后端 172 项：默认 164 通过、8 项外部依赖检查跳过；启用 Redis 与 MinIO 真实检查时为 170 通过、2 项收费模型冒烟跳过。JUnit 覆盖鉴权/CSRF、资源归属、Range、上传补偿、任务幂等、重试/Outbox、时间对齐、索引来源、引用、问答准入以及 Agent 协议/预算/终态保护。测试使用 H2、可控模拟及本地协议服务器。

真实模型冒烟只有显式设置 COURSETRACE_LIVE_AI=true 才运行。普通测试不会因为已配置模型 Key 就自动启用它。

## 真实业务验收

本地已经用自写合成语音课程执行上传、Kafka、FFmpeg、ASR、笔记、Embedding/Qdrant、普通问答与 Agent，验证引用定位和重启持久化。故障检查包括本项目 Kafka、MinIO、Qdrant 暂停与恢复；浏览器检查涵盖桌面、手机和矮屏。

原始执行日志、业务 ID、模型响应、录屏和开发过程文档保留本地，不作为仓库内容上传。样片原文和题目在 docs/demo，可公开复现，不能当作真人长课准确率或大规模负载基准。

## 浏览器与集成脚本

scripts 中保留浏览器、故障与演示脚本，便于检查实际流程。需要 Edge、Playwright，以及相应的本地素材/业务数据；部分历史回归使用既有演示课程，不能视为全新机器上的独立测试套件。

统一入口 scripts/verify-m7.ps1 的检查范围：

| 模式 | 行为 |
|---|---|
| Build | 后端测试、前端构建和脚本语法，不主动调用收费接口 |
| Flow | 新 RunId 的短视频真实处理和课程问答，会创建数据并调用模型 |
| Fault | 顺序暂停本项目依赖、检查故障与重启，并恢复服务 |
| Regression | 已有里程碑与页面回归，可能使用历史请求/素材或创建测试数据 |
| Refine | 指定回答质量问题的真实定向重测 |
| Demo | 使用已有真实数据录制演示，不新建问答 |
| Report | 核对必需报告、成片、运行构建和服务健康 |

Flow / Fault / Demo 等模式有素材与先后依赖，不属于默认无副作用检查。默认 Build 是最小验证入口。

## 范围说明

当前测试证明小样本功能、协议和异常处理行为。引用存在不自动证明语义完全正确；模型 usage 和预留调用次数也不等同于完整费用账单。生产部署、真人课程准确率、高并发和长课压力尚未纳入本次验证。

## 上传与令牌桶增强验收

新增上传测试覆盖分片摘要/大小、缺片、重复与冲突、跨用户、取消/过期、幂等完成、领取过期恢复、晚到结果、存储清理和 CSRF。Redis 适配测试覆盖拒绝、指纹冲突和故障关闭；真实 Lua 检查验证双桶不部分扣减、补充与 TTL、并发不超发、用户隔离和同身份重放。真实 MinIO 检查覆盖当前 SDK 的对象合并。

显式运行真实本地依赖检查（不调用模型）：

```powershell
$env:COURSETRACE_LIVE_REDIS="true"
$env:COURSETRACE_LIVE_STORAGE="true"
.\scripts\maven.ps1 test
```

可选环境变量只对当前终端生效，结束后可移除。Redis 测试用独立随机前缀，不 FLUSHDB；MinIO 测试使用随机 integration 前缀并清理自己的对象。

`scripts/test-upload-upgrade.mjs` 是有副作用的真实集成入口，需要已有自写合成样片 `.local/m7/sample-course.mp4`、Edge/Playwright 和运行中的服务。它会创建验收课程，把原样片补零到 18 MiB 以跨三个分片验证传输；字节填充仅用于测试文件大小，不能作为真人长课或吞吐基准。脚本验证暂停、刷新、IDEA 重启、仅补缺片、完成响应丢失后的确认、完整摘要、Range、跨用户和 Kafka 资源检查，并临时停止后恢复本项目 Redis 验证故障策略。

默认不新建模型任务。显式设置 `COURSETRACE_UPGRADE_LIVE_AI=true` 后，额外对新视频运行 ASR、笔记、索引、普通问答和 Agent；固定 RunId 保存任务/请求身份，复跑成功分组明确标为 REUSE，避免当作新增验收。该脚本限流页面检查在未启用新模型时复用本机原 M7 验收视频，并非全新空库通用脚本。
